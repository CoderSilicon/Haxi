## Security

If you believe you have found a security vulnerability in Haxi, please report it responsibly.

### What to report
- Any security issue that could affect users' data or safety.
- Issues in how the app handles medical information.
- Problems with the journal storage or data privacy.
- Any other concern related to the security of the application.

### How to report
- Send a detailed description of the issue to the project maintainers.
- Do not exploit the vulnerability for any reason.
- Allow reasonable time for a fix before discussing it publicly.

### What to expect
- The maintainers will acknowledge receipt of your report within 14 days.
- A fix will be prioritized based on the severity of the issue.
- You will be credited in the security policy (unless you request to be anonymous).

### Severity guidelines
- **Critical**: Complete bypass of safety features, user data exposure. Expected fix: within 7 days.
- **High**: Significant risk to user safety or privacy. Expected fix: within 14 days.
- **Medium**: Minor security concern that does not directly affect user safety. Expected fix: within 30 days.
- **Low**: Cosmetic or minor issue. Expected fix: when convenient.

All reports will be handled with care. Thank you for helping keep Haxi safe for everyone.
